# GuessANumber
En: This game is about guessing a 4-digit number.

The program randomly chooses a number between `0000` and `9999`, you have to find it following these

## RULES

* Send a first attempt, you will receive feedback.
* A **green card** means a digit is correct and in its correct position.
* A **blue card** means a digit is correct, but not in its place.
* A **red card** means a digit is not part of the number.
* The main objective is to find the number in the minimum attempts.
> **Keep in mind**: numbers can have repeated digits (e.g., `0402`).
